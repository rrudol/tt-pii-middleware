PL-PII redaction — static showcase

Precomputed examples from tt-pii-middleware (Apache-2.0). Hugging Face free tier does not host Gradio/Docker Spaces without PRO, so this page shows fixed synthetic before/after pairs. Run the live UI locally:

git clone https://github.com/rrudol/tt-pii-middleware
cd tt-pii-middleware && make install
# optional Docker demo:
make demo-local   # http://localhost:7860
Guardrails (when you run it yourself): redact-only, max 2000 chars, rate limit, never log raw text. Do not paste real production PII. Redaction ≠ GDPR compliance.
